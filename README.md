# FluxCash 💸

> Software de gestão financeira pessoal focado em automação de investimentos e estética Dark/Neon.

## 🚀 Sobre o Projeto
O **FluxCash** nasceu da necessidade de centralizar a gestão de aportes mensais e categorização de gastos de forma automatizada. O projeto foca em uma interface moderna utilizando **PySide6** e uma lógica de processamento eficiente em **Python**.

Este é um projeto desenvolvido para fins de aprendizado em Análise e Desenvolvimento de Sistemas, focando em:
- Manipulação de dados e automação.
- Interface Gráfica (GUI) avançada.
- Lógica de investimentos compartilhados.

## 🛠️ Tecnologias
- [Python 3.10+](https://www.python.org/)
- [PySide6](https://doc.qt.io/qtforpython/) (Interface Gráfica)
- [Git](https://git-scm.com/) (Controle de Versão)

## 📋 Funcionalidades (MVP)
- [ ] Processamento de transações via terminal/input.
- [ ] Categorização automática via palavras-chave (Mapeamento Reverso).
- [ ] Cálculo de saldo disponível vs. Meta de aporte mensal.
- [ ] Suporte para diferenciação de aportes individuais e conjuntos.
